1 Registro — Verificación de identidad
👤 Usuario
Ingresa nombre, email y teléfono
Formulario web / QR presencial
→
🖥 Frontend → Backend
Valida y busca en Firestore
POST /api/auth/register
Body: { nombre, email, telefono }
→
🔁 Backend responde
4 posibles respuestas según estado
🚫 ya_voto
Ya participó. Se bloquea el flujo.
⚡ habilitado
Sesión activa. Salta al Paso 3.
📧 pendiente
Existe pero no verificó. Reenvía OTP.
✅ nuevo
Crea usuario + envía OTP por correo via n8n.
Firestore usuarios: nombre email telefono estado: "pendiente" otpHash: SHA-256 otpExpiresAt: now + 60s
↓
2 Verificación OTP — Código de 6 caracteres por correo
👤 Usuario
Ingresa código OTP recibido por correo
6 chars · mayúsculas · 60s vigencia
→
🖥 Frontend → Backend
Verifica código contra hash en Firestore
POST /api/auth/verify-otp
Body: { userId, code }
🔒 Rate limit: 5 intentos / 10 min
→
🔁 Backend responde
3 posibles resultados
✅ válido
estado → habilitado. Pasa al Paso 3.
❌ incorrecto
Código equivocado. Puede reintentar.
⏱ expirado
Pasaron 60s. Muestra botón reenviar.
🔄 Reenvío de código
Usuario pide nuevo OTP (tras 60s)
POST /api/auth/resend-otp
Body: { userId } · Rate limit: 3 reenvíos / 10 min
⚡ Sobreescribe hash → código anterior inválido de inmediato
↓
3 Votación — Web o Presencial
🌐 Modalidad Web
👤 Usuario
Selecciona Candidato A o Candidato B
🖥 Frontend → Backend
Registra voto digital anónimo
POST /api/votes
Body: { userId, candidato: "A"|"B" }
🗄 Firestore
candidato: "A" o "B" modalidad: "web" createdAt
Usuario → estado: ya_voto · modalidad: web
✅ "¡Voto registrado exitosamente!"
🏛 Modalidad Presencial
👤 Usuario
Muestra pantalla "Habilitado ✅" al jurado
👮 Jurado → Backend
Registra participación presencial
POST /api/votes/presencial
Body: { userId }
🗄 Firestore
candidato: null modalidad: "presencial" createdAt
Usuario → estado: ya_voto · modalidad: presencial
🗳️ Jurado entrega tarjetón físico al votante
↓
📊 Resumen de votaciones (admin)
🖥 Admin
Consulta el conteo de votos
GET /api/votes/summary
→
{
  "web": {
    "A": 120,

    "total": 218
  },

Referencia de Endpoints
Método Ruta Descripción Body
POST /api/auth/register Registro e inicio del flujo OTP { nombre, email, telefono }
POST /api/auth/verify-otp Verifica el código OTP { userId, code }
POST /api/auth/resend-otp Reenvía nuevo OTP (invalida anterior) { userId }
POST /api/votes Registra voto digital (web) { userId, candidato }
POST /api/votes/presencial Registra participación presencial { userId }
GET /api/votes/summary Conteo de votos por modalidad —
